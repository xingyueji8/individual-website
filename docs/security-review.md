# 星月集安全复核 · 2026-11-18

**范围：** Worker、Studio、登录页面、文章/文件分享、Word 预览及 QQ 通知的源码和本地集成测试。验证使用独立的 D1、R2、账号和签名测试数据。此记录不是生产渗透测试、历史入侵调查、完整依赖审计或 Cloudflare 账户配置证明。

| 修复项 | 影响 | 当前行为 |
|---|---|---|
| 文件预览和下载 | 部分只能下载的附件曾只经过浏览授权；普通资源地址没有统一检查是否已进入网站 | 普通文件、图片入口检查访问者身份和资源权限；任何作为附件返回的内容还要验证下载权限。明确授权的分享和公开登录背景分别验证。合法的视频分段播放和 PDF 预览仍可用 |
| 密码重置 | 同一链接存在并发重复改密的窗口；重复提交找回申请还可能让已签发的链接提前失效 | 重置、撤销会话、消耗链接在同一事务中受有效凭证约束。重复申请不作废现有链接。新链接不再把凭证放入 HTTP 请求地址 |
| 登录草稿 | 手机页面刷新时，网站曾从标签页存储中读取明文密码 | 只保存用户名和勾选状态，登录页载入时清理旧草稿。密码仍支持系统自动填充 |
| Studio Access | 启用可选邮箱白名单时，后台曾直接信任邮箱请求头，仍另有后台密码校验 | 从经签名、签发域、应用 AUD、类型及有效期验证的 Access 身份中读取邮箱，并继续验证后台密码 |
| QQ 通知 | 未固定接收人且没有绑定口令时，首个绑定可能拿到后续通知；未配置独立口令时，回调地址验证也会放行 | 首次或更换接收人必须有正确口令或固定 OpenID；回调地址验证需独立口令。正常已签名事件仍单独验签 |
| Word 和登录后跳转 | 文档转换结果和账户返回地址过去只过滤部分输入 | 按允许的排版元素重建文档。只保留内嵌位图和允许的链接，站外跳转不携带来源；登录返回地址解析后须为本站 |

**站长检查：** 见 [部署说明](deploy.md) 的 Studio Cloudflare Access、私有文件存储入口和 QQ 官方机器人提醒。未启用 Access 或 QQ 的站点无需为这两项添加变量。若已启用 Access 邮箱白名单，须补齐团队域名及应用 AUD 才能登录 Studio。若使用 QQ 接收注册或找回密码通知，确认实际接收账号确属站长。

仅在线浏览不代表防录屏，也不能撤回接收者此前已经保存的文件。Word 若不开放原件下载，需要有 PDF 预览版才能在线阅读。生产日志、外部视频服务的独立播放策略及历史数据访问不在本次验证范围内。
